# ADR-0003: 스토어 업로드는 EAS 자동 제출 대신 Transporter

- 상태: 채택됨
- 결정일: 2026-10-01
- 소급 작성일: 2026-11-24

## 맥락

앱 빌드는 EAS Build로 만들고, 결과물(IPA)을 App Store Connect에 올려야 합니다. EAS 자동 제출(`eas submit`, 빌드 옵션의 자동 제출)을 쓰면 빌드 뒤 업로드까지 한 번에 되지만, 여러 번 제출이 대기열(`IN_QUEUE`)에서 30분 가까이 움직이지 않았습니다. 에러 코드나 로그는 남지 않았고, 서비스 상태 페이지는 정상이었습니다.

## 결정

배포는 `eas build`로 빌드까지만 자동화하고, 업로드는 항상 **Apple Transporter**로 직접 합니다. `eas submit`과 자동 제출 옵션은 쓰지 않습니다.

## 검토한 대안

- **EAS 자동 제출**: 편하지만 정체가 반복돼 쓰지 않기로 했습니다. 취소한 정체 건은 모두 한국 시각 밤 10시에서 자정 사이(미국 오전)였지만, 무료 플랜 대기열 우선순위 때문인지는 확인하지 않았습니다.

## 결과

- 얻는 것: 업로드 시간이 예측 가능하고, 정체 원인을 따지지 않아도 됩니다. 같은 버전과 빌드 번호를 그대로 올릴 수 있습니다.
- 감수하는 것: 빌드가 끝난 뒤 IPA를 내려받아 올리는 수동 단계가 남습니다. 정체 원인은 지금도 확정하지 못했습니다.
