# 설계 결정 기록 (ADR)

0001~0005는 2026-11-24에 이미 내려진 결정을 소급해서 정리한 것입니다. 번호는 작성 순서이고 결정일과 무관합니다.

## 쓰는 규칙

- 새 결정은 `NNNN-kebab-case.md`로 다음 번호를 받아 추가하고 이 표에 한 줄 넣습니다. 형식은 저장소의 `docs/adr/0000-template.md`를 따릅니다.
- 확정된 ADR은 상태 줄 외에는 고치지 않습니다. 결정이 바뀌면 새 ADR을 쓰고 옛 ADR의 상태만 `대체됨(→ ADR-NNNN)`으로 바꿉니다.
- 한 화면(40~60줄) 안에 씁니다. 상세는 구조 문서나 설계서로 연결합니다.
- 검토한 대안은 근거 문서에 실제로 적힌 것만 씁니다. 개인 사정과 내부 식별자는 넣지 않습니다.
