# ADR-0005: 비밀값은 .env와 EAS 환경변수에만 둔다

- 상태: 채택됨
- 결정일: 2026-08-27
- 소급 작성일: 2026-11-24

## 맥락

이 저장소는 공개 저장소입니다. 소스에 하드코딩된 OAuth 클라이언트 시크릿이 커밋돼 공개 저장소에 올라간 일이 있었고, 해당 시크릿은 발급처에서 재발급했습니다.

## 결정

API 키나 시크릿을 소스에 직접 쓰지 않습니다.

- 로컬에서는 `.env`(gitignore)에 두고, 형식은 추적되는 `.env.example`로 보여 줍니다. 코드는 `process.env.EXPO_PUBLIC_*`로 읽습니다.
- EAS 클라우드 빌드용 값은 `eas env:set`으로 프로젝트에 등록합니다.
- 제공사가 클라이언트에 넣도록 설계한 값(OAuth 클라이언트 ID, 카카오 네이티브 앱 키)은 `app.json` 설정에 둬도 됩니다. 시크릿이 아니기 때문입니다.
- 보안 점검은 현재 파일뿐 아니라 git 이력 전체를 대상으로 합니다.

## 검토한 대안

비교한 기록은 없습니다. 이력에 남은 시크릿을 지우려는 이력 재작성은 되돌리기 어려워서, 재발급으로 처리하고 재작성은 하지 않았습니다.

## 결과

- 얻는 것: 저장소가 공개여도 시크릿이 노출되지 않습니다. 새 키를 추가할 때 따를 규칙이 분명합니다.
- 감수하는 것: `EXPO_PUBLIC_` 값은 앱 번들에 들어가 사용자가 볼 수 있습니다. 그래서 정말 비밀이어야 하는 값은 앱이 아니라 서버가 들고 있어야 합니다. OTA 배포 스크립트는 배포 전에 로컬 `.env` 값이 번들에 들어가는지 확인해야 합니다.
